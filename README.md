# IPZStream

Plataforma propia de gestión y distribución de streaming.

## Estado
**Etapa 1 — Base visual + instalador inicial**

La primera versión establece el lenguaje visual del panel y una ruta de instalación en un único contenedor Linux. La funcionalidad de datos todavía es demostrativa; API, base de datos, autenticación y motor de streaming se incorporarán por etapas.

## Documentación de continuidad
- `CONTINUITY.md` — reglas, arquitectura y etapas.
- `BITACORA.md` — registro obligatorio de mejoras y correcciones.
- `INSTALL.md` — instalación en contenedor.

## Regla de cambios
Toda mejora o corrección debe registrarse primero en `BITACORA.md`. Después se implementa, se verifica y se publica la actualización.
